one installer, a whole hyprland desktop

A curated configuration that replaces the default Arch look with a polished Hyprland setup. One wallpaper drives every colour on screen via pywal16 — with XFCE kept installed as a safety net.

features

what you get

pywal16 theming

Dynamic colour scheme generated from your wallpaper. Terminal, bar, rofi, icons — everything updates in sync.

one-command installer

A guided gum TUI auto-detects your distro, then installs package groups, dotfiles and services.

modular lua config

Hyprland config split into 18 Lua files — keybindings, monitors, window rules, animations, decorations.

wallpaper tools

Random change, a rofi picker and the matuwall film-strip viewer. pywal16 applies colours instantly.

clipboard & screenshots

cliphist for clipboard history, grim + slurp + swappy for region screenshots, wf-recorder for capture.

lock & session

swaylock-effects with blur, hyprlogout power menu, SDDM login manager — all pre-themed.

nvidia & amd support

Dedicated nvidia.lua with environment variables and DRM handling. AMDGPU setup included.

utility scripts

Wallpaper, volume, brightness, recording, clipboard, font search, snapper, QEMU/virt and more.

xfce fallback

Wayland-first, but XFCE stays installed as a safety net — a familiar desktop if Hyprland misbehaves.

install

Back up your existing ~/.config first. The installer walks you through package groups, dotfiles and services.

clone & run — distro auto-detected

$ git clone https://github.com/hyprtk/dotfiles.git ~/hyprtk && cd ~/hyprtk && sh ./1-install.sh
