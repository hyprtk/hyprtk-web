two projects

the dots and the bar

hyprtk is a pair of projects that share one theme engine. The dotfiles install and theme everything; hyprtk-bar is the taskbar that lives on top of it.

dotfiles

hyprtk dots

A single installer for a fully themed Hyprland desktop on any Arch-based distro — with XFCE kept as a safety net.

  • 11 distros, one guided gum installer
  • pywal16 — one wallpaper drives every colour
  • Hyprland config in modular Lua
  • rofi, swaylock, SDDM, Papirus & more, pre-themed
full breakdown → repo
taskbar

hyprtk-bar

A modular, feature-complete taskbar for Hyprland — GTK3 + layer-shell, themed live from your pywal16 palette.

  • Start menu, arc menu, task list & workspaces
  • Built-in notification daemon & system tray
  • Quick settings, system monitor, theme manager
  • Re-themes instantly on wallpaper change

get started

Back up your existing ~/.config before running the installer.

dotfiles — clone & run, distro auto-detected

$ git clone https://github.com/hyprtk/dotfiles.git ~/hyprtk && cd ~/hyprtk && sh ./1-install.sh

hyprtk-bar — standalone, any Hyprland

$ git clone https://github.com/hyprtk/hyprtk-bar.git && cd hyprtk-bar && ./install.sh
the bar ships bundled with the dots too — no second step needed
