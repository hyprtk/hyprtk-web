hyprtk-bar

A modular, feature-complete taskbar for Hyprland. It hosts app launchers, workspaces, a task list, system monitoring, a system tray, quick settings and a built-in notification centre — all themed live from your pywal16 palette.

install it view on github
features

everything in one bar

fully modular

Arrange modules across left / center / right sections, show or hide them, reorder them — from the settings window, no config surgery.

live theming

One wallpaper drives the whole palette via pywal16. The bar re-themes itself the moment the palette changes — zero restart.

task list

Pinned and running apps grouped by class, with a running/active indicator, hover previews, click to focus or minimize.

notification centre

A built-in org.freedesktop.Notifications daemon — toasts plus a centre panel with actions and clear-all. No separate daemon.

system tray

Full StatusNotifier support, including native dbusmenu menus rendered directly in the bar.

quick settings

Wi-Fi and Bluetooth toggles, a volume slider with mute, and a brightness slider — auto-hidden when no backlight exists.

system monitor

A Mission Center-style dialog — CPU, Memory, Disks, Network, GPU and Apps pages with live graphs and per-process kill/launch.

start menu

Search, category sidebar, favourites, recents and a power bar — in four layouts: whisker, win7, win11, plasma.

arc menu

A radial launcher — a FAB in a screen corner fans out a ring of app shortcuts, Android Material style.

theme manager

Wallpapers, pywal palette, rofi variants, bar themes, matuwall, swaylock, icons and SDDM & GRUB — one dialogue.

multi-monitor

One bar per monitor when configured, each with its own active workspace. Tray and notifications stay on the primary.

clipboard manager

In-bar history with list, copy, delete and wipe — replaces a separate cliphist script.

the modules

Every module is optional and positionable. The default arrangement puts launchers left, workspaces centre, status right.

install

The installer detects your package manager and installs the GTK3 / layer-shell typelibs, a virtualenv, and the launcher.

standalone — any Hyprland

$ git clone https://github.com/hyprtk/hyprtk-bar.git && cd hyprtk-bar && ./install.sh
config lives in ~/.config/hyprtk-bar/config.json — it ships with the dots too
